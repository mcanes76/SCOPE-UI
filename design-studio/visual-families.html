Selection and comparison

Guided Workshop → Material shows four family cards, followed by that family's palettes. Advanced Editor → Visual roles & family defaults exposes all 27 semantic colors, structural geometry, glass effects and contrast guidance. Task 1 Component Styles still supplies hover, focus, pressed, selected, disabled and loading overrides at global, category, application and individual scopes.

Changing a palette preserves the chosen font, custom geometry and explicit style overrides. “Use recommended typography” applies the palette's font recommendation deliberately. “Reset appearance to family defaults” removes color/material/region/component overrides, including parameter-level component defaults, and restores recommended typography; branding, navigation and application arrangement remain. Undo restores the preceding design.

“Compare two themes on this arrangement” alternates A/B on the same live preview. It freezes operator interaction and changes CSS without rebuilding application DOM, models, view maps or layout. Existing explicit tokens and geometry remain during comparison so only inherited styling changes. Finish simulated loading first. Escape or Cancel restores the original design; Keep displayed theme commits only the palette. Candidate checkpoint comparison is separate and may compare different designs or layouts.

Semantic contract

visual-tokens.schema.json describes optional design.visual. theme-presets.schema.json describes the catalog. theme-tokens.js owns role resolution, generated interactive states, family metadata and contrast guidance. visual-system.js compiles the resolved roles into shell, navigation, application, table, form, window and dialog styles, then applies explicit Task 1 component overrides.

{
  "visual": {
    "schemaVersion": 1,
    "tokens": {"application.background": "#172536", "focus.ring": "#65C8FF"},
    "effects": {"transparency": true, "blur": false, "reflections": true, "motion": false}
  }
}

Tokens use literal dotted keys and six-digit HEX colors. The complete roles are:

border.default, border.strong, focus.ring

Inheritance: palette roles → legacy design.colors aliases → explicit visual role overrides → scoped component overrides. Existing application semantic controls keep Join green, Leave red, Warning yellow and Create/Update violet. Intentional explicit action-color overrides remain supported with warnings and labels.

Catalog version 1 colors/roles are normalized at runtime. Version 2 presets include complete token maps, tokenSchemaVersion: 1 and variant metadata (ID, light/dark mode, recommended font and provenance). Saved design schema 1 stays compatible; missing visual settings inherit. Unknown visual versions, role keys and invalid colors are rejected. No palette ID migration is required.

Hover and pressed surfaces derive from coordinated palette colors; foregrounds are selected for readability. Disabled surfaces retain distinct styling and a readable foreground. Advanced Editor warns when checked token pairs fall below 4.5:1. These calculations concern solid role pairs and do not certify composited glass, images, all statuses or custom gradients. Review on the target display.

Parameters and export

Use the canonical palette ID in params.json; family is an optional consistency constraint. A family without a palette does not choose an arbitrary variant. Supported family aliases are technical-workbench, field-operations and glass-experimental.

{
  "schemaVersion": 2,
  "initial": {"family": "field", "theme": "low-luminance-amber"},
  "branding": {"name": "SCOPE"},
  "logoPath": "assets/logo.png"
}

A mismatched family/palette is rejected. Importing parameters preserves selected typography. Full parameters keep application names, tabs, navigation labels and logo configuration. Folder exports load local configuration over HTTP; direct-file JSON fetching can be restricted. Standalone exports embed the effective configuration and logo, and support explicit parameter/logo imports offline.

Design JSON, candidate checkpoints, CSS overrides, standalone operator HTML, configurable ZIP and Final Presentation share the same compiler. JSON/checkpoints retain explicit values; compiled CSS contains effective roles and overrides. All 14 installed-font choices remain available across families, with no external font download. Appearance depends on locally installed fonts. Standalone operator HTML excludes Studio editors and comparison controls.

Design-system references

SCOPE-owned palettes use role separation and surface-state concepts informed by IBM Carbon color guidance, Radix scale composition, USWDS theme tokens and shadcn/ui theming conventions. No brand palette is reproduced. These are documentation links, never runtime dependencies.
